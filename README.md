# Spotify Clone 🎧

A simple, Spotify-inspired music website built using HTML and CSS as part of a web development workshop.

## Pages

- **Home:** Hero section, email sign-up form and featured playlists.
- **Browse:** Music categories including Pop, Hip-Hop, Chill and Workout.
- **Playlist Details:** Playlist information and a track list with artist names and durations.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Responsive design

## Features

- Three linked pages with shared navigation.
- Dark theme with green accents.
- Playlist cards and music-themed images.
- Hover effects and a responsive layout.

## How to Run

Download or clone this repository and open `index.html` in a web browser.

## Purpose

This project was created for educational purposes to practise HTML structure, CSS styling, layouts and navigation.
